# Benchmarks on a synthetic ~80k corpus (2026-09-26)

Regenerate with `uv run python -m tests.bench.report_80k` (from `backend/`, on a quiet machine: other load
inflates the timings); never edit by hand. Budgets are
spec 03 §Performance budgets. Verified clauses are exempt from the `match_ids` budget (spec 03), so they
are reported, not gated.

- Machine: macOS-15.6.1-arm64-arm-64bit, arm64, 8 CPUs; Python 3.12.9,
  tantivy 0.26.2; commit `18a7513-dirty`; index `27659e65468c`.
- Corpus: `tests/fixtures/corpus/synthetic_5k.records(80000, (120, 250))`, 80,000 records (generated in
  6.9 s): the differential corpus's generator with abstracts of 120-250 words.
